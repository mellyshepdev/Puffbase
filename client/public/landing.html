Puffbase is the Black Sheep forge: mirror repos from GitHub or GitLab, sync issues with Linear, edit in the browser, push and deploy from the command line, and watch what it all costs to run.

Open the console Browse the forge
⇄

Mirror from anywhere

Pull-mirror repos from GitHub or GitLab — they stay in sync hourly. git remote add puff https://git.prime-quality.online/<you>/<repo>.git

✓

Linear sync

Issues flow both ways between Linear and the forge — file it in one place, track it in both.

⌨

Edit in the browser

The built-in code editor commits straight to the branch — no clone needed for the quick fixes.

⬆

Push & deploy from the CLI

git push puff main then let the runner take it — pipelines deploy on merge.

◉

Usage tracking

Traffic, latency, deploys and storage per service — the console's Analytics page reads live counters, not vibes.

⚙

Pipelines included

A self-hosted runner (unit7) is attached — push a .gitea/workflows/ file and it runs.
